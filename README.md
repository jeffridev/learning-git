# Learning Git

Repositorio de aprendizaje y práctica de **Git y GitHub**.

## Objetivo

Practicar el control de versiones y comprender los flujos de trabajo con repositorios locales y remotos.

## Temas de estudio

- Commits e historial de cambios
- Ramas y fusiones
- Repositorios remotos
- Colaboración mediante pull requests

## Estado

📚 En aprendizaje. Este README describe el propósito del repositorio; no implica que todos los temas ya estén implementados.
